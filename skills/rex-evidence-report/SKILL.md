# REX Evidence & Report Engine Skill

## Evidence Standard
Every material claim must be backed by verifiable evidence. **AI-generated guesses must never be presented as confirmed facts.**

## Confidence Levels
- **Confirmed:** Directly verified via primary artifact (e.g., magic bytes, manifest/descriptor entry, exact disassembly, or verified runtime log).
- **Strongly supported:** Corroborated by 2+ independent static signals.
- **Probable:** Single strong heuristic or decompiler reconstruction with minor ambiguity.
- **Unverified:** Hypothesis requiring dynamic execution or missing dependencies.
- **Contradicted:** Disproven by deeper inspection (retained in audit trail).

## Report Separation Rule
Every report generated by `rex.reporting.engine` separates:
1. **Observed facts** (hashes, headers, descriptors, imports, strings)
2. **Evidence-backed interpretation**
3. **Hypotheses & Unknowns**
4. **Limitations & Unperformed Tasks** (missing tools, obfuscation, static-only scope)
